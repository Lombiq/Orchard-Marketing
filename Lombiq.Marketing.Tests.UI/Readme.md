# Lombiq Marketing for Orchard Core - UI Test Extensions

[![Lombiq.Marketing.Tests.UI NuGet](https://img.shields.io/nuget/v/Lombiq.Marketing.Tests.UI?label=Lombiq.Marketing.Tests.UI)](https://www.nuget.org/packages/Lombiq.Marketing.Tests.UI/)

## About

This project contains UI test extensions for the Lombiq Marketing modules.

## Documentation

This project contains helpers and test cases for the marketing modules.

Right now it covers these main scenarios:

- Managing short URLs from the Orchard admin.
- Checking Pirsch client-side tracking injection.

You can use it from a UI test project that already uses Lombiq's Orchard Core UI testing infrastructure.
